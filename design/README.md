# Laptop sticker

The sticker leads with The Friday Commit, matching the site's pink Friday, off-white Commit, and purple cursor. Code & Coffee sits below the command, with the original hand-authored terminal mug alongside the headline and fridaycommit.dev in the footer.

- Editable artwork: `laptop-sticker-editable.svg`. Text uses Liberation Mono Regular and Bold.
- Outlined artwork: `../public/brand/laptop-sticker.svg`. All lettering is SVG paths, with no font or external image dependencies.
- Light artwork: `laptop-sticker-light-editable.svg` and `../public/brand/laptop-sticker-light.svg`. The same layout uses an off-white background and the site's darker pink, purple, and cyan accents.
- Nominal artwork size: 4 × 2.49 inches. SVG scales without losing detail.

The rounded silhouette is the intended sticker edge, off-white on the dark version and pale purple on the light version. Corners outside it are transparent. Ask the printer to confirm its cut contour and bleed requirements before ordering. These files do not include a printer-specific cut layer or bleed.

After editing a source, convert its text to paths in an SVG editor and replace its outlined export. Preserve the dimensions and accessibility title and description. The website displays the matching light or dark sticker in the Find the table section, following the page theme. The original compact marks remain available in public/brand.
